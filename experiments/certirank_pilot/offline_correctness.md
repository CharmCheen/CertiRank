# 离线正确性与覆盖边界

复现：`uv run --no-project --with pytest python scripts/check_offline.py`。
也可在已安装 `requirements-dev.txt` 的 Python 环境中运行 `python scripts/check_offline.py`。
脚本验证外部数据、历史审计、测试、成本情景和生成产物，不调用模型。

## 已覆盖

- 契约负例：对调候选、条件/模型/参数漂移、原文与判定冲突、第二解析器缺失、
  非整数槽位、缺失/重复响应、query entry 重排、全文件统一模型漂移。
- N=4 全部 64 张二元反对称比较表，K=1/2/3/4，每表逐一翻转六个请求决策。
  共 1,536 个单次更新对照，包含非传递输入。
- N=1/3/6/8 各 60 张固定 seed 随机表，每表四轮更新，每轮最多翻转三个请求；
  共 960 轮链式更新。与独立递归重建参考逐次核对。
- N=5/7/16/31/64 的不同 K 再覆盖 750 轮链式多请求更新。
- N=4、K=1/2/3 上，已判定 conditional safe/impact 的请求逐一核对所有未观察边补全。
- 四元素相同轨迹的两种补全：翻转 C>D 后，A:D 未观察，必须 unresolved；
  A>D 与 D>A 两种补全产生不同冠军。
- 严格全序、非传递三元环、非二次幂叶数、Top-1/Top-3/全部提取、重复请求缓存。
- 新分支已在全局表内仍需计费；预算不足两次、修复途中预算耗尽、缺失响应，
  均保留最后完整输出并记账。预算耗尽前不得预读下一响应。
- 不重叠槽位组验证与跨执行缓存隔离；单组分歧估计拒绝生成伪独立结果。
- 三个在线策略在固定 seed 下，增量执行与合法缓存重放的选边、完整输出、
  状态和调用账目相同；执行器计数包含中止工作。
- 非法预算在读取前拒绝；复核 session 禁止复用旧 ledger；Vote3 与单响应模式隔离，
  失败账目终止后不能再次读取同一响应槽位。
- 评价记录携带 source/query/N/K/算子身份；跨查询或数据源拒绝汇总，
  基础执行失败保留账目并阻止不完整样本的分歧估计，中止回退输出仍计入分母。
- 审计和成本估算独立验证源清单；清单/契约失败时提前停止，不写成功产物。
- 历史 420 条响应的契约、15 次 naive 重放、15 次 Tournament 重放一致性、
  48 行单组策略 smoke、全部 10 个重叠子集的描述性敏感性产物。

## 保证范围

有限穷举与固定 seed 随机测试支持上述实现模型的正确性，未提供一般数学证明。
比较关系允许非传递；同请求复用在一次执行中采用单一当前决策。
单请求反事实对其他决策固定，不代表未来重采样概率或多边免疫证书。
策略访问隔离为 API 层约束，真实网络、HTTP 重试、token/费用硬上限尚未接入。

历史请求没有完整 prompt 正文和可重建 hash 的全部来源代码，故只能校验导出 hash、
逐字段一致性、固定模型元数据与来源 manifest，无法在本仓库独立重建 wire request。
