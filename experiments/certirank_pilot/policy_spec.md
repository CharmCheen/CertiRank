# 离线策略接口与状态（2026-10-15）

实现语义：`configs/offline_protocol.json`，版本 `0.2.1-offline-review`。
本文件固定工程接口；研究主策略尚未冻结，不构成 P4 method freeze。

## 访问范围

策略只接收不可变 `PolicyView`：当前执行已观察的请求与判定、已复核集合、
当前完整 Tournament 轨迹、剩余预算。该对象不持有响应源或全局表引用。
Python 层的 API 隔离用于实验防误用，不提供对恶意代码的进程级沙盒。

请求按冻结候选行序呈现（i<j），不交换 A/B。历史数据复用要求保持该呈现顺序。
新采集若改为文档 ID 排序，需要重建请求身份并单独编号。

## 方法

| 方法 | 规则 | 状态 |
|---|---|---|
| Base | 单响应、无复核 | 已实现 |
| Random | 从已观察且未复核的请求中随机选取，固定 seed | 已实现 |
| SimpleTopology | 到根距离越小越优先；同距离按 canonical pair 排序 | 已实现 |
| TraceSensitivity | conditional impact 优先，其次 unresolved，再次 conditional safe；用 SimpleTopology 打破平局 | 开发候选，收益未验证 |
| Vote3 | 每个实际遇到的请求都取三个响应做多数票，按真实路径计调用 | 已实现，高成本参考 |
| Confidence | 低 logprob margin | unavailable；历史响应没有可用 logprobs |
| OracleImpact | 全表补全单请求翻转反事实 | 仅诊断；未实现最优策略上界，不参加可部署排名 |

距离按二叉树节点到根的边数定义；同一请求多次出现时取最小值。
每轮策略运行后重新计算可见视图，复核最多一次，最多消耗两个新响应槽位。
预算不足两次时停止选边；不能通过取整扩大预算。

## 执行与修复

预算 B=floor(b×L0)，其中 L0 为该执行无复核路径的唯一请求读取次数。
显式复核、新分支首次读取、失败的读取尝试都计入逻辑账目；本次分析的物理调用为零。
请求缓存仅在一次完整执行内复用。多算法可以使用同一响应组做配对比较，
不同独立执行组必须互不重叠。

复核多数票改变判定时，增量模式从上次完整执行的初始树局部更新，再执行固定提取。
对照模式从头构建树并复用全部合法缓存。两者必须看到相同新响应，输出、状态、
策略选边与调用账目一致；只允许执行器工作量不同。

修复预算耗尽或缺少响应时保留最后完整输出，记录 pending pair、已消耗调用与错误原因，
终止该执行。已经花费的复核调用不会回滚。该输出保留在评价分母中。

## 评价边界

历史 5 响应只容纳一个不重叠三槽位组。单组 smoke 的 D_EM 为 null。
10 个重叠三槽位组合只做组合敏感性描述，不用于置信区间或独立重复数。
正式评价需新增查询组、每对 12 响应、冻结策略与 query-group 划分。
当前三个历史查询均已暴露给开发，不得划入未来留出集。

评价行携带 source_id、query_id、N/K、算子版本及失败/中止状态。
source_id 绑定响应表内容和 query/request context；真实数据构造器必须传入对应 context。
汇总拒绝跨源、跨查询或不同配置混合，也拒绝重复/缺失/越界 Top-K。
基础执行失败时 topk=null，保留调用账目，整组分歧估计标为不可计算；
已有完整输出的 aborted 执行保留回退输出并计入分母，不进行成功子集筛选。
执行入口在任何响应读取前验证预算与槽位，ledger 禁止跨 session 复用或混合 Vote3 模式。

未冻结 Proposed、未选择最强 comparator、未执行 query-group bootstrap 或正式质量 gate。
当前实现的节点求值次数仅为工作计数；策略 CPU 分析和端到端延迟未测，H3 收益待验证。

## v0.3 研究设置修正

当前设置由 `configs/experiment.json` 实际驱动；详细规范以 `docs/experiment_protocol_v0.3.md` 为准。
TraceSensitivity 保留为结构基线。新增 ReviewValue 分桶统计估计器，在独立开发响应组上
估计单步一致性代理、质量和修复成本；不使用留出样本拟合，当前历史池不可用。
预测随动作记录，完整算法的收益由冻结评价判断，不能从正的代理值直接推出。
策略主实验统一用 cached_replay；增量执行单独测完整 CPU。
历史组合敏感性改为 30 种均衡初始槽位角色分配，仍不给独立分歧估计。
