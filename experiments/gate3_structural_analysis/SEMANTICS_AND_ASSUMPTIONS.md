# SEMANTICS_AND_ASSUMPTIONS — Gate 3 Structural Analysis

本文件逐项声明本研究的全部语义选择、假设与依赖关系。任何结论若依赖某项假设，正文引用本文件编号（S1…S12）。

研究身份：Exploratory Mechanism Study（Gate B1/B2/B3），基于 Gate 3 正式实验缓存数据（NFCorpus · GLM-5.3-Flash @ Paratera · temperature=null · N=8/K=3 · 每对 12 次重复），协议 `0.3.0-research-pilot`，代码版本 git `6ee9919`。零新增 LLM 调用；零修改原始数据与冻结协议；全部新产物位于 `experiments/gate3_structural_analysis/`。

## S1. 数据与判断张量

- 来源：`data/gate3_nfcorpus/formal/{dev,heldout}/pair_calls.jsonl`（6,368 条原始调用记录）与 `workload.json`（pair 元数据、文档行序、qrels）。
- 判断张量：`Y[q][(i,j)][r] ∈ {True,False}`，`(i,j)` 为规范化无序对（`i<j`，按候选行序枚举 28 对），`r ∈ {0..11}` 为重复槽位。
- `True` 的语义：pair 中**较小行序位置**的文档获胜。该语义直接取自原始字段 `strict_parsed_decision`（`Document 1` = `position_i` = 较小索引；`provider.py` 的 prompt 构造已核验）。
- 完整性（本沙箱独立核验 + 继承 Gate 3 独立审计 A 的契约结论）：18 个 Query-group × 28 对 × 12 槽位，无缺失、无重复、无不可解析响应；本沙箱在加载时再次强制断言（任何异常直接报错）。
- **禁止重新解释**：不明确的 Verdict 不存在（0 条 invalid），无需任何宽松解析。

## S2. Frozen Pairwise World（合成耦合，S2 假设）

- 定义：world(slot r) = `{(i,j) ↦ Y[q][(i,j)][r]}`，即某 Query 在槽位 r 的全部 28 个判断。
- **假设 S2（合成耦合）**：把同一槽位 r 的 28 次独立 API 调用视为一个内部一致的判断世界。原始采集是逐对逐槽位的独立请求（每次调用有独立 `provider_request_id` 与时间戳），服务端不保证同一槽位内跨 Pair 的任何联合分布。
- 该假设与 Gate 3 正式执行语义**完全一致**（官方 Base 执行 = 槽组初始槽 {0,3,6,9} 构成的 world 内运行锦标赛，决策缓存保证执行内一致），因此本研究的 Frozen World 结果与官方 D_EM 可直接对照（已验证：tournament 在官方 4 槽位上的 D_EM 与官方 Base D_EM 逐 Split 精确相等）。
- 局限：跨 Pair 的真实联合分布不可观测；若真实服务端存在跨调用相关性，Frozen World 分析不能声称反映真实联合分布。Call-level Resampling（S9）作为对照。

## S3. 执行内决策缓存（在线可复现语义）

- 一次执行内，某 Pair 第一次被比较时读取其判断并**固定**；后续再访问同一 Pair 为缓存命中（Gate 3 ledger 语义：cache hit 不计费）。
- 四个算子使用完全相同的缓存语义。
- 事实（216 个真实 world 上核验）：tournament 与 quickselect 在 N=8/K=3 下**从不**在单次执行内重复访问同一 Pair（cache_hits=0）；minheap 在 65% 的 world 中会重复访问（sift 重比较）；fullcompare 每对恰读一次。
- 在线/离线信息边界：反事实重放读取的"新比较"是**离线缓存数据**，在线算法在真实执行中必须为此付费调用 LLM；本研究从不把缓存中的未来响应当作在线算法可提前访问的信息（B2 的 Method B 只记录新比较，不暴露给任何模拟在线策略）。

## S4. 物理算子（计划定义的输出）

所有算子：固定候选行序、固定 tie-breaking、确定性、Pair 规范化 `(i<j)`、共享 S3 缓存。

1. **Tournament**（`fixed_leaf_tournament_v1`，生产算子，从协议文档独立重实现）：定叶锦标赛，叶按行序补齐到 2 的幂（N=8 恰好满树），初始自底向上建树；提取阶段输出根胜者、移除其叶、仅重算其祖先。输出 = 提取顺序（有序）。
2. **MinHeap Top-K**：维护大小 K 的最小堆（根 = 当前保留中最弱者），新候选仅与根比较，胜则替换。输出集合 = 堆内容；有序输出 = 逐次弹出弱者的逆序。
3. **Quickselect Top-K**：Lomuto 划分（pivot = 子区间末元素），确定性，对任意（含非传递）比较器保证终止。输出 = 选择完成后前 K 个槽位的文档集合；**槽位内部顺序不构成排名语义**（集合语义专用）。
4. **FullCompare + 显式排名规则**（参考计划）：读取全部 28 对，按胜场数降序稳定排序（平局按行序升序，即 LOTUS naive 语义）。排名语义已显式声明；**不**声称该规则在非传递判断下给出唯一"正确"全局排序。

**计划定义原则**：非传递比较器下，算子输出是该物理计划定义的结果；计划间输出差异不被解释为正确性差异。传递性全序 Oracle 下四算子必须且已经返回一致的正确 Top-K（2,016 项检查，0 失败；见 `results/sandbox_validation.json`）。

## S5. 反事实语义（B2）

- **翻转对象**：仅轨迹内**已执行判断**（base 执行访问过的 unique Pair）。未执行 Pair 的单点翻转对确定性计划无影响（其执行是所读判断的确定函数）。
- **Method A（Fixed-trace）**：反事实重放只能使用原始轨迹已有的判断；需要轨迹外新比较时返回 UNRESOLVED，禁止猜测。
- **Method B（Branch-aware Replay）**：从初始状态在扰动后的 Frozen World 上完整重跑计划；新访问 Pair 从该 World 读取（S2 假设下），记录为新的逻辑比较。不实际调用 LLM。
- 两种方法**从不混合比较**；A 可解析时与 B 必然一致（同一世界、同一计划——实测 100% 一致，作为正确性检查）。
- **双边翻转**：对轨迹内全部执行对做 C(m,2) 完全枚举（N=8 可承受），无近似。

## S6. 扰动与保证语义（B3）

- 扰动集合：`W_b = {w : w 与 w0 在 ≤ b 个已执行判断上不同}`。
  - **Empirical 模型**：新访问 Pair 取指定完整缓存 World（w0 的值）。结论为经验稳定性。
  - **Worst-case 模型**：新访问且 base 轨迹未执行的 Pair 允许任意合法判断（两分支全枚举）。只有该模型支持相对于明确定义扰动集合的确定性证书。
- 保证目标：**Top-K 成员集合**相等（与协议 D_EM 的集合语义一致）。有序列表相等仅作次级报告。
- 传递性：**不假设任何传递性**。禁止 `(A>B) ∧ (B>C) ⇒ (A>C)` 推理。
- 同一 World 内同一 Pair 必须一致（S3 缓存 + DFS forced-values 保证）。
- b=0 恒可认证（平凡）：与 w0 在全部已执行判断上一致的世界产生逐位相同的执行（确定性归纳）。
- 预算：节点上限 200,000 / 单实例墙钟 20s；超限返回 **UNKNOWN**，绝不当作稳定。未将超时计为 certified。

## S7. 认证搜索的可靠性

- 精确 Oracle = 分支树 DFS（b≤2, N=8 完全枚举，测试中与暴力全世界枚举在 n=4 上逐实例对齐，b=0/1/2 全部一致）。
- 剪枝 P1（记忆化）：以 (forced-values, 剩余预算) 为键复用搜索结果；不减分支、不改判定（测试核验）。
- 剪枝 P2（tournament 边界规则，b=1）：
  - **Soundness 论证**：胜者移除锦标赛中，被提取的每个成员在其参与的全部比较中获胜——更精确地，成员只可能输给更早提取的成员（输给任何非成员即从树中永久消失，无法再进入任何节点）。因此凡一端为当前 Top-K 成员、另一端为非成员的已执行比较，其判断翻转必然驱逐该成员 → 集合必然改变。故 certified(b=1) ⇒ 轨迹中不存在跨界已执行对；而 K=3 个成员分布在 4 个相邻叶对中，鸽笼原理保证至少一个叶对是混合的 → 跨界对必然存在 → 每次执行都 violated。
  - 该规则在全部 216 个 tournament 执行上与精确 Oracle 逐一对账（0 违反即报告，否则记为 soundness violation）。

## S8. 统计口径

- 评价单位 = Query-group（18 个：dev 6 + heldout 12；每 group 恰 1 个 Query）。
- 多个 Pair、12 个 World、反事实分支**从不**当作独立 Query；跨 World 指标先在 Query 内聚合再跨 Query 平均。
- 本轮全部发现标记 **Exploratory**（该 18 组已用于前序研究与审计；不构成独立确认性证据）。
- 配对比较（算子间逐 Query D_EM 差值）+ 精确符号检验 + Query 级 bootstrap（2,000 次，种子 17）——均为描述性，不用于宣称确认性显著。
- 零效应与不利案例全部如实报告；不筛 Query、不事后改口径。
- 事后 Oracle 类信息（如跨槽组联合观察）不写成在线可实现收益；稳定性改善不写成准确性改善。

## S9. Call-level Resampling（补充语义，仅敏感性分析）

- 语义：每次新鲜比较独立均匀抽取 12 个槽位之一（执行内缓存仍固定该值）。**无**执行内跨 Pair 世界一致性。
- 与 Frozen World 结果**分开报告**，绝不与 S2 结果混合或直接对比得出机制结论。
- 用途：检验 S2 合成耦合假设对不稳定性测量的影响方向与幅度。

## S10. 输入顺序与 Tie-breaking

- 主实验：固定候选行序（`document_order`，采集时冻结）。
- 顺序敏感性诊断：4 个固定置换（恒等、逆序、2 个固定 shuffle）下重算 D_EM12。置换实现为候选位置的重新映射（Pair 判断按原位置对齐重 canonical 化）。
- 结论依赖：任何"算子 A 比 B 稳定"的表述必须对照输入顺序效应的量级（B1 实测两者同量级）。

## S11. 不做的事

- 不开发生产系统；不扩展 N / 数据集 / 组合搜索范围（N=8 精确枚举受限内进行）。

## S12. 已知局限

1. 18 个 Query-group、单一模型（GLM-5.3-Flash）、单一数据集（NFCorpus）、N=8/K=3 —— 效应量的外部效度未知。
2. 12 槽位 Worlds 是合成耦合（S2）；真实联合分布不可观测。
3. B3 的 b≤2 限制由预算决定；b≥3 的外推不保证。
4. 算子实现为语义级独立重实现（与官方代码逐行为对齐后从协议文档重写；官方 144 行 Base 执行记录 100% 复现作为正确性锚点），非官方代码的二进制执行。
5. Worst-case 模型假设新比较可取任意值，这是对真实模型行为的保守上界（真实模型对新 Pair 的判断有边际分布）；两种模型分开报告以避免夸大。
